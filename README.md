# Codex 18 v6 — os 18 conceitos essenciais

Curso gratuito do [INEMA.CLUB](https://inema.club) no formato v6 (iniciante 30+): 18 aulas de ~15 minutos, cada uma com uma cena ilustrada e um visual real em cada passo, para quem nunca usou o Codex e não programa. Projetos, AGENTS.md, o ciclo do agente, /goal, local × nuvem, worktrees, a pasta .codex, modelos, esforço, permissões, skills, a pasta .agents, plugins, navegador, sites, subagentes, tarefas agendadas e modo de voz.

**Abrir o curso:** https://inematds.github.io/curso-codex-18-v6/

Versão mais longa e técnica (formato v2): https://inematds.github.io/curso-codex-18/

Manutenção: edite `aulas/aula-N.html`, rode `python3 ~/.claude/skills/formato-curso-v6/scripts/montar-curso.py .` e audite com `auditar-curso.cjs` (todas ≥9/10) e `testar-motor.cjs`.
